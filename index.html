cryptic_sorter

📄 py_cryptic_sorter.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui trie une liste de chaînes selon plusieurs critères, appliqués dans l'ordre suivant :

  1. Tri principal — par longueur de chaîne (la plus courte en premier).
  2. Tri secondaire — alphabétique (pour les chaînes de même longueur).
  3. Tri tertiaire — par nombre de voyelles (ascendant, pour chaînes identiques lexicalement).

Signature

def cryptic_sorter(strings: list[str]) -> list[str]:

Contraintes

  • Gérer les chaînes vides et la liste vide.
  • Casse mixte : traiter comme minuscule pour le tri alphabétique.
  • Caractères spéciaux : ignorés pour le compte des voyelles.

Exemples

cryptic_sorter(["apple", "cat", "banana", "dog", "elephant"])
["cat", "dog", "apple", "banana", "elephant"]
cryptic_sorter(["aaa", "bbb", "AAA", "BBB"])
["AAA", "aaa", "BBB", "bbb"]
cryptic_sorter(["hello", "world", "hi", "test"])
["hi", "test", "hello", "world"]
cryptic_sorter([])
[]
cryptic_sorter([""])
[""]
💡 Pièges courants
  • Penser à fournir une clé de tri qui combine les trois critères dans le bon ordre.
  • La casse intervient deux fois : tri alphabétique (lowercase) puis départage par chaîne d'origine.
▶ Voir la solution 
def cryptic_sorter(strings: list[str]) -> list[str]:
    def is_vowel(c):
        return c.lower() in 'aeiou'

    def key_func(s):
        length = len(s)
        vowel_count = sum(1 for c in s if is_vowel(c))
        return (length, s.lower(), s, vowel_count)

    return sorted(strings, key=key_func)

echo_validator

📄 py_echo_validator.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui vérifie si une chaîne est un palindrome, en ignorant les espaces et la casse, et en ne considérant que les caractères alphabétiques.

Signature

def echo_validator(text: str) -> bool:

Contraintes

  • Ignorer espaces, ponctuation et tout caractère non alphabétique.
  • Ignorer la casse (comparaison en minuscule).
  • Une chaîne vide retourne False.

Exemples

echo_validator("racecar")
True
echo_validator("A man a plan a canal Panama")
True
echo_validator("race a car")
False
echo_validator("Was it a car or a cat I saw")
True
echo_validator("hello")
False
echo_validator("Madam I'm Adam")
True
echo_validator("")
False
💡 Pièges courants
  • Ne pas oublier le cas particulier de la chaîne vide qui doit renvoyer False.
  • Filtrer d'abord (ne garder que les lettres), normaliser ensuite (minuscule), puis comparer.
▶Voir la solution 
def echo_validator(text: str) -> bool:
    if text == "":
        return False
    new_text = "".join(c.lower() for c in text if c.isalpha())
    start = 0
    end = len(new_text) - 1

    while start < end:
        if new_text[start] != new_text[end]:
            return False
        start += 1
        end -= 1

    return True

valid_parentheses

📄 py_valid_parentheses.py 🚫 Aucun import autorisé

Énoncé

Lis une chaîne sur l'entrée standard et détermine si les parenthèses, crochets et accolades qu'elle contient sont correctement équilibrés et imbriqués. Affiche True si la chaîne est valide, False sinon.

Trois paires de symboles à gérer :

  • ( ouvre · ) ferme
  • [ ouvre · ] ferme
  • { ouvre · } ferme

Règles

  • Chaque symbole ouvert doit être refermé par le bon symbole correspondant.
  • L'ordre d'imbrication doit être respecté.
  • Une chaîne vide est considérée comme valide.

Exemples

"()"
True
"()[]{}"
True
"(]"
False
"([)]"
False
"{[]}"
True
💡 Pièges courants
  • Penser à utiliser une structure LIFO (pile) pour vérifier la correspondance.
  • Une fermeture qui arrive sans ouverture correspondante invalide la chaîne immédiatement.
  • À la fin, la pile doit être vide — sinon il reste des ouvertures non refermées.
▶Voir la solution 
def is_valid_parentheses(s):
    stack = []
    pairs = {'(': ')', '[': ']', '{': '}'}
    for char in s:
        if char in pairs:
            stack.append(char)
        elif not stack or pairs[stack.pop()] != char:
            return False
    return len(stack) == 0


def main():
    s = input().strip()
    print("True" if is_valid_parentheses(s) else "False")


if __name__ == "__main__":
    main()

number_base_converter

📄 py_number_base_converter.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui convertit un nombre d'une base vers une autre. Bases supportées : de 2 à 36 inclus, en utilisant les chiffres 0-9 et les lettres A-Z pour les valeurs 10 à 35. Retourne "ERROR" en cas d'entrée invalide.

Signature

def number_base_converter(number: str, from_base: int, to_base: int) -> str:

Contraintes

  • Bases valides : 2 ≤ base ≤ 36.
  • Un caractère du nombre doit appartenir à l'alphabet de sa base de départ.
  • Le résultat doit utiliser les majuscules pour les chiffres > 9.

Exemples

number_base_converter("1010", 2, 10)
"10"
number_base_converter("FF", 16, 10)
"255"
number_base_converter("255", 10, 16)
"FF"
number_base_converter("123", 10, 2)
"1111011"
number_base_converter("Z", 36, 10)
"35"
number_base_converter("35", 10, 36)
"Z"
number_base_converter("123", 1, 10)
"ERROR"
number_base_converter("G", 16, 10)
"ERROR"
💡 Pièges courants
  • Le cas num == 0 doit explicitement renvoyer "0" et non une chaîne vide.
  • Toute exception levée par la conversion d'entrée doit produire "ERROR".
  • int(number, base) en Python lève une exception si la base est invalide ou si un chiffre n'appartient pas à la base.
▶Voir la solution 
def number_base_converter(number: str, from_base: int, to_base: int) -> str:
    base_str = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"
    try:
        num = int(number, from_base)
        if num == 0:
            return "0"
        res = ""
        while num > 0:
            res = base_str[num % to_base] + res
            num //= to_base
    except Exception:
        return "ERROR"
    return res

pattern_tracker

📄 py_pattern_tracker.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui compte le nombre de paires de chiffres consécutifs valides dans une chaîne. Une paire valide est constituée de deux chiffres adjacents, où le second est strictement supérieur au premier.

Attention : un 9 suivi d'un 0 n'est pas une paire valide.

Signature

def pattern_tracker(text: str) -> int:

Contraintes

  • La paire doit être composée de deux chiffres ; un caractère non numérique entre les deux casse la paire.
  • Les paires se chevauchent : dans "123", on compte (1,2) et (2,3).

Exemples

pattern_tracker("123")
2
pattern_tracker("12a34")
2
pattern_tracker("987654321")
0
pattern_tracker("01234567")
7
pattern_tracker("abc")
0
pattern_tracker("1a2b3c4")
0
pattern_tracker("112233")
2
💡 Pièges courants
  • Toujours vérifier que les deux caractères sont des chiffres avant de comparer.
  • Comparer directement les caractères avec > fonctionne car '0' < '1' < ... < '9' en ASCII.
▶Voir la solution 
def pattern_tracker(text: str) -> int:
    count = 0
    for i in range(len(text) - 1):
        if text[i].isdigit() and text[i + 1].isdigit() and text[i + 1] > text[i]:
            count += 1
    return count

shadow_merge

📄 py_shadow_merge.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui fusionne deux listes triées d'entiers en une seule liste triée.

Signature

def shadow_merge(list1: list[int], list2: list[int]) -> list[int]:

Contraintes

  • Les deux listes d'entrée sont déjà triées par ordre croissant.
  • Les doublons doivent être conservés.
  • Gérer le cas où l'une des listes (ou les deux) est vide.

Exemples

shadow_merge([1, 3, 5], [2, 4, 6])
[1, 2, 3, 4, 5, 6]
shadow_merge([1, 2, 3], [4, 5, 6])
[1, 2, 3, 4, 5, 6]
shadow_merge([1], [2, 3, 4])
[1, 2, 3, 4]
shadow_merge([], [1, 2, 3])
[1, 2, 3]
shadow_merge([1, 1, 2], [1, 3, 3])
[1, 1, 1, 2, 3, 3]
💡 Pièges courants
  • Approche simple : concaténer les deux listes puis trier — accepté ici.
  • Approche optimale : fusion à deux pointeurs (O(n+m) au lieu de O(n log n)).
▶Voir la solution 
def shadow_merge(list1: list[int], list2: list[int]) -> list[int]:
    list1.extend(list2)
    list1.sort()
    return list1

string_sculptor

📄 py_string_sculptor.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui transforme une chaîne en alternant la casse des caractères alphabétiques uniquement. Les caractères non alphabétiques restent inchangés et ne comptent pas dans l'alternance.

La première lettre est en minuscule, la deuxième en majuscule, la troisième en minuscule, et ainsi de suite.

Signature

def string_sculptor(text: str) -> str:

Exemples

string_sculptor("hello")
"hElLo"
string_sculptor("Hello World")
"hElLo wOrLd"
string_sculptor("abc123def")
"aBc123DeF"
string_sculptor("Python3.9!")
"pYtHoN3.9!"
string_sculptor("")
""
💡 Pièges courants
  • Regarde bien l'exemple "Hello World" : après l'espace, l'alternance recommence à minuscule. L'espace fait office de reset.
  • Les chiffres et symboles sont copiés tels quels sans affecter le compteur d'alternance.
▶Voir la solution 
def string_sculptor(text: str) -> str:
    res = ""
    lower = 1
    for c in text:
        if c.isalpha() and lower:
            res += c.lower()
            lower = 0
        elif c.isalpha():
            res += c.upper()
            lower = 1
        elif c.isspace():
            res += c
            lower = 1
        else:
            res += c
    return res

whisper_cipher

📄 py_whisper_cipher.py 🚫 Aucun import autorisé

Énoncé

Écris une fonction qui implémente un chiffre simple (César) en décalant chaque lettre d'une chaîne d'un certain nombre de positions. Les caractères non alphabétiques restent inchangés.

Signature

def whisper_cipher(text: str, shift: int) -> str:

Contraintes

  • La casse doit être préservée (les majuscules restent majuscules).
  • Le décalage est circulaire dans l'alphabet (z + 1 → a).
  • Le décalage peut être négatif.
  • Caractères non alphabétiques : recopiés tels quels.

Exemples

whisper_cipher("hello", 3)
"khoor"
whisper_cipher("Hello World!", 1)
"Ifmmp Xpsme!"
whisper_cipher("xyz", 3)
"abc"
whisper_cipher("ABC123def", 5)
"FGH123ijk"
whisper_cipher("", 10)
""
💡 Pièges courants
  • Travailler avec les codes ASCII : retrancher 65 (A) ou 97 (a) avant le modulo, puis rajouter.
  • Le modulo % 26 en Python gère naturellement les décalages négatifs.
▶Voir la solution 
def whisper_cipher(text: str, shift: int) -> str:
    res = ""
    for c in text:
        if c.isalpha() and c.isupper():
            res += chr((ord(c) - 65 + shift) % 26 + 65)
        elif c.isalpha():
            res += chr((ord(c) - 97 + shift) % 26 + 97)
        else:
            res += c
    return res
